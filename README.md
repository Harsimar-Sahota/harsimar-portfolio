## 🛠️ Local Development

Clone the repository:

```bash
git clone https://github.com/<your-username>/harsimar-portfolio.git
cd harsimar-portfolio
````

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The site will be available at:

```
http://localhost:3000
```
